# Md. Sadiqur Rahman Toky — Portfolio

A modern, dark agency-style portfolio built from the supplied Word document. Includes project images, filterable project grid, galleries, skill bars and contact links. Pure HTML/CSS/JavaScript, no build process required.

## Preview locally

Open `index.html` in your browser. For an HTTP preview, run `python -m http.server 8000` from the folder and visit `http://localhost:8000`.

## Publish using GitHub Pages

1. Create a new public GitHub repository (for example, `my-portfolio`).
2. Upload **the contents of this folder** to the repository root, including `index.html`, `style.css`, `script.js`, and `assets/`.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, and folder **/(root)**. Save.
4. After deployment, GitHub Pages will provide a URL such as `https://YOUR-USERNAME.github.io/my-portfolio/`.
